App & Product Design

Hackers Range
(*Student side)

Industry Cybersecurity Training & LMS Platform
Product Overview

Hackers Range is the ultimate cybersecurity training and up-skilling platform, combining real-world simulations with gamification to make practical, hands- on expertise accessible while keeping the experience educational, engaging, competitive, and fun. HackersRange is a hands-on cybersecurity training and simulation platform that enables organizations, academies, and vendors to create and deliver interactive cyber labs, gamified training, and structured learning paths in realistic environments. The platform supports onboarding, skill evaluation, and real-world scenario practice through a multi-role system with dedicated admin and student experiences.

Student Environment Screens Design:

The student side is the execution layer of the platform where learners access and complete the training content created in the LMS. Courses and games dynamically present tasks, labs, and learning materials based on the structure defined in the admin environment. The experience is designed to keep users focused on completing challenges while providing supporting learning resources such as videos, PDFs, and lessons when neede

My Role

Designed the student experience from scratch by translating the complex content structure defined in the admin platform into a clear, modular, and user-friendly interface.

  • Created dynamic layouts that render courses, games, and labs based on LMS data
  • Structured the UI to keep users focused on completing challenges while allowing seamless access to learning materials
  • Ensured visual and functional consistency across all learning scenarios
UX Challenges
  • Transforming a complex backend structure into a simple learning flow Content created in the admin system had to be presented in a clear and logical way for students.
  • Designing for multiple content types Tasks, cyber labs, HTML simulations, videos, PDFs, and lessons all needed a consistent and flexible layout.
  • Maintaining focus during interactive training The interface had to support game mechanics (clues, skipping tasks, scoring) without distracting from the learning goal.
  • Creating a scalable modular system The UI was built to support new task types and future content without redesigning the core screens.
Outcome
  • Clear and engaging hands-on learning experience
  • Modular UI that adapts to different course and game structures
  • Seamless connection between LMS configuration and student-facing content
